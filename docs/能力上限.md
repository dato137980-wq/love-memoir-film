# 能力上限与工具要求

## 上限取决于三部分

本 Skill 提供导演与执行规则；AI 助手负责理解、看图和调用工具；生成/剪辑后端负责产出媒体。只有三部分都到位并获得授权，才有机会完成从图片到短片的全流程。文字模板本身不能提升模型的物理能力或绕过平台限制。

| 能力 | 可做到 | 条件与实际限制 |
|---|---|---|
| 故事与视听设计 | 从想法发展关系线，每镜说明景别、角度、运动和表达目的 | 不擅造真人经历；故事需要真实素材或明确虚构设定 |
| 身份与服装控制 | 为参考图分配身份/衣服/动作职责，检查镜间连续性 | 无法保证所有角度、遮挡与跨模型生成都完全一致 |
| 视频提示词 | 按实际模型写时间顺序、动作、机位和衔接要求 | 时长、参考数量和参数以实际工具为准，不承诺固定长提示词一定有效 |
| 手部与表情返修 | 定位错误，区分保留区域和改动区域，选择最小返修 | 后端没有局部编辑能力时，整段重生可能改变原表演 |
| 无缝转场 | 设计运动方向、遮挡、接点与颜色连续性 | 真实动态遮罩、跟踪或复杂合成需要额外工具；提示词不能保证一次完成 |
| 配乐剪辑 | 真正试听后设计情绪与切点，检查声画承接 | 没有音频感知就不能声称听过；自动分析只是辅助 |
| 本地媒体工具 | 探测、抽帧、生成 HTML、按清单硬切导出 MP4 | Python＋FFmpeg；不是 AI 生成器、专业非线编或自动卡点软件 |
| 封面 | 选帧、文案、画幅与字体布局设计；有图像工具时制作 | 修改不能保证百分之百保留脸；字体效果和平台裁切需要检查 |

## 本地渲染器的明确边界

`filmkit.py render` 根据帧数和源入点组接片段，支持显式变速、等比留边或居中裁切，并合入指定音乐。复杂转场必须先完成并检查，再作为一个片段输入。

它不调用 AI 模型，不做区域修手、光流、动态遮罩、自动音乐卡点。它不保留源片对白或现场声，只编码所指定的音乐为 AAC；需要多轨音效与现场声时用专门的时间线工具。

工具会拒绝越界片段、不明确的静音设置、过短音乐（除非明确允许补静音）、不支持的转场和覆盖既有文件。通过技术检查不等于已经看过画面或听过声音。

## 费用、时间和成片品质

本包不包含会员、生成积分或保证免费使用的后端。实际费用受模型、时长、分辨率、重试次数影响。助手应在新付费生成前说明具体方案与费用，并在既有授权范围内执行，不无限重试。

不能保证生成一次即用、人物绝对一致、手部永不出错、原表情逐帧保留或任何平台都一键直出。约 30 秒样片可作为提案，不是能力上限，也不是每部片的固定时长。长作品需要分批管理资产和连续性。

## 已验证和未验证

现有 v1.0.0 的离线检查见 [validation.json](../love-memoir-film/validation.json)。8 项测试使用合成素材验证本地工具，不是公开用户真实素材的成功率统计。Windows 环境已测；其他系统、宿主、真实新用户照片/音乐与各生成模型没有全面验收。

## 想得到更好结果

提供清楚且一致的人物参考，明确最想保留的一个瞬间；有旧素材就全部交给助手审查。生成后先看动作和表情，再看花哨运镜。满意部分保留，问题部分定点返修，最后在真实音乐下检查完整成片。
