# 安装与首次使用

## 1. 下载完整包

从[下载入口](../downloads/love-memoir-film-v1.0.0.zip?raw=true)保存 ZIP 并解压。GitHub 若先显示文件页，请点击下载原始文件。也可在仓库首页选择 Code → Download ZIP，再取其中的 `love-memoir-film` 文件夹。

不要只下载 SKILL.md；参考文件、模板和脚本需要一起保留。

## 2. 安装到 Codex

将整个 `love-memoir-film` 文件夹放进自己的 Codex 技能目录。默认用户目录示例：

```text
Windows: %USERPROFILE%\.codex\skills\love-memoir-film\SKILL.md
macOS / Linux: ~/.codex/skills/love-memoir-film/SKILL.md
```

如果你自定义了 CODEX_HOME，请用对应的 skills 目录。路径示例是安装说明，其他系统运行效果尚未测试。避免解压后出现两层同名目录。已有同名版本时先备份或对比，不要直接覆盖自己的修改。

让宿主重新加载技能；必要时重新打开应用或新建对话。在技能选择器中找 `love-memoir-film`，或输入 `$love-memoir-film`。能否运行生成/剪辑由宿主实际工具决定。

其他支持 Skill 的助手：按照它的技能安装机制放置完整目录。只支持文件上传时，可上传全包并要求实际读取 SKILL.md 及其引用；不能保证所有助手都支持执行脚本。

## 3. 准备最少的输入

- 每位需要露脸的人物清楚照片；一个人物只有一张照片也可以先起方案，复杂角度可能需要补图。
- 一句想法，例如“她在旅途中回头拉住我，最后到婚礼”。
- 可选：侧脸/全身、要保留的服装、已有片段、音乐、发布画幅、时长与预算。

两个人都露脸就给两人的参考；只有一个人照片时可采用另一人不露脸的第一视角。不要在 GitHub Issues 上传私人素材。

## 4. 发出第一条指令

```text
使用 $love-memoir-film。根据我上传的照片和想法开始。
先看完已有素材，提出一条关系线，给出有表达目的的分镜、
人物服装连续性表、逐段视频提示词和可复制的制作 HTML。
检查你实际能用的工具；新增付费生成前告诉我内容、数量和费用。
```

之后按实际情况继续：

```text
我手动生成好了，这是返回的视频。请检查人物、衣服、手和动作衔接，
挑出最好用的片段；只针对问题返修，不重做满意部分。
```

```text
结尾抬眼笑很好，请保留这段表演，只修握手。
若工具只能重生整段，先说明会影响哪些部分，再给最小改动方案。
```

```text
用我上传的音乐剪辑。实际听过后再做音乐情绪判断；
无法试听时明确标记，不把波形当听过。
```

## 5. 接收结果

有生成和剪辑工具时，检查返回的实际 MP4、版本和审查记录。没有生成工具时，拿提示词到自己的平台生成，再把结果交回助手。下载完整包后可双击 `使用指南.html`，也可查看 [HTML 工作台示例](../love-memoir-film/assets/example-workbench.html)；GitHub 文件页展示的是源码，本地浏览器才会渲染 HTML。

## 常见问题

**装完找不到？** 检查目录层级、SKILL.md 是否在第一层，确认宿主已重新加载。

**为什么没直接出视频？** Skill 没有内置视频模型；确认当前助手是否真正接入可用的生成工具。

**能用即梦或别的平台吗？** 可以由助手根据实际接口适配，或你手动生成；本包不附带这些平台的账号、插件和额度，不宣称全部已测试。

**脚本缺 ffmpeg？** 文字方案与 HTML 仍可完成；媒体处理前安装并使 FFmpeg 和 ffprobe 在 PATH 中可用。详见[本地工具](../love-memoir-film/references/local-tools.md)。

**基础渲染后现场声没了？** 基础渲染器只合入指定音乐。对白、原片现场声、多轨混音要使用其他编辑工具，不适合直接交给该脚本。
