# 质检与局部返修

## 实际审查
覆盖整条视频时间范围的抽帧用于定位；手部、遮挡、接触、跳切附近另看连续帧，必要时完整播放。稀疏联系表不证明每帧无瑕。没有播放/听觉能力时只写实际查看的帧范围。
- 身份：脸、发缝、耳饰是否稳定，有无混脸。
- 造型：同一时空的领口、袖口、肩带和裙摆是否一致。
- 空间：左右、地平线、进出方向与目光是否成立。
- 手部：腕部归属、接触顺序、遮挡前后、是否多指/融合/换手。
- 摄影：到底是下摇还是举手；第一视角有无意外第三人称。
- 表演：情绪是否变化、是否倒放复用微笑、哭笑幅度。
- 接缝：全覆盖、边缘、残色、背景穿透、双脸、曝光和运动跳变。
- 交付：长度、比例、黑帧、音轨、字幕与用户排除镜头。

## 两列反馈
每次记录 keep 与 change，带素材/时间窗。不要仅凭最后一句覆盖整片。用户要“保留结尾表情，修手”就是两个同时成立的条件。

从小到大选修法：
1. 改剪点/用现有合格素材，检查是否丢了用户要看的动作。
2. 当前平台确有区域编辑或后期修复能力时只改受影响区域，再验证脸没变。
3. 补生成局部动作或尾段，用实际遮挡/动作/声音连接。
4. 整段重生仅在局部办法不够时使用，先做具体方案与报价，按授权执行。

裁掉手是避开缺陷，不是修好解剖；用户要看握手时裁切不满足任务。叠化也不是手部修复。重生成保留的是表演方向，不能保证原表情逐帧不变。
并排检查旧/新版：缺陷是否改善，满意部分是否损失，有无新问题。手更清楚但表情更弱时如实说明取舍。不满意不自动付费重试。
样例中的手工遮罩坐标、音乐、人物与时长不可写成所有项目通用常量。
