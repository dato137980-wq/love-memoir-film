# 恋爱回忆录导演 · 公开版

**上传人物照片，说出一个想法，让 AI 助手陪你把恋爱、旅行和婚礼回忆做成短片。**

`love-memoir-film` · v1.0.0 · 中文 Skill 模板

从“我想拍她回头看我的瞬间”，到有表达目的的分镜、可复制的视频提示词，再到素材检查、返修、配乐混剪与封面。这套模板把制作经验变成可复用的流程，让不懂导演术语的人也能开始。

**它是一套给 AI 助手使用的工作方法，生成视频仍需要你自己的工具、账号和额度。**

[下载完整 Skill ZIP](downloads/love-memoir-film-v1.0.0.zip?raw=true) · [安装与首次使用](docs/快速开始.md) · [能力上限与工具要求](docs/能力上限.md) · [完整使用说明](love-memoir-film/README.md)

## 先看它能帮你做什么

| 你提供 | 助手负责组织 |
|---|---|
| 清楚的人物照片＋一句想法 | 关系线、场景、动作和每个镜头的表达目的 |
| 指定人物、衣服、想保留的画面 | 身份参考分工、服装和动作连续性 |
| 已有照片或视频 | 审查完整素材，挑选可用部分，避免只用开头几秒 |
| 想要的转场与情绪 | 分镜、镜头运动、衔接条件、逐段视频提示词 |
| 生成后的片段 | 找出手部、表情、人物漂移、跳切等问题并提出局部返修 |
| 音乐与真实可用的媒体工具 | 试听条件核实、节奏方案、剪辑和成片检查 |

## 三步开始

1. 下载上面的 ZIP，解压出 `love-memoir-film` 文件夹，按[安装说明](docs/快速开始.md)放到助手支持的 Skill 目录。
2. 上传需要露脸的人物照片；有喜欢的衣服、旧视频或音乐可以一起给。
3. 复制下面这段话，把自己的想法补进去：

```text
使用 $love-memoir-film。
这是我们的人物照片。我想做一条有生活感的恋爱回忆录，
从她回头看我开始，经历几件旅行小事，最后走向婚礼。
请先看图片和现有素材，保持人物和衣服连续，
设计每个镜头的表达目的，给出可复制的视频提示词和制作 HTML。
先核实你能使用哪些生成、听音频和剪辑工具，再执行实际能完成的步骤。
新增付费生成前，说明这次要生成什么、数量和费用。
```

这只是示例。婚礼、回头、第一视角、片长和画幅都可以换成你的需求。

## 实际能交付到哪一步

| 使用环境 | 可交付内容 |
|---|---|
| 助手能看图、读文件 | 创意、分镜表、参考图分工、完整提示词、HTML 制作页 |
| 你在视频平台手动生成 | 助手给提示词和参考绑定方法；返片后继续审查和剪辑设计 |
| 助手有生成与剪辑工具，且你已授权 | 实际生成、检查、返修、混剪 MP4 和封面；具体上限取决于工具 |

**不能承诺一张图一次生成就得到完美成片。** 人脸、手部、表情和复杂转场可能需要返修。Skill 不包含视频模型、付费会员、免费积分或其他私人导演库。完整边界见[能力上限](docs/能力上限.md)。

## 这套流程重视什么

- 每个镜头都有叙事或情绪目的；景别、角度、焦段、机位高度和运镜一起设计。
- 满意的表情和动作要明确保留；修手时不能悄悄把整段表演换掉。
- 无缝转场需要核对遮挡、方向、人物位置和动作接点，不能把普通擦除称为真实过肩转场。
- 音乐没有实际听过就明确说明；波形与自动节拍分析不等于试听。
- 检查所有素材并选择最有效的部分，镜头数量和时长服务内容。

## 包内有什么

```text
love-memoir-film/
  SKILL.md                  技能入口
  agents/openai.yaml        宿主展示信息
  references/               导演、工具、质检、剪辑、封面与案例规则
  assets/                   项目模板、提示词模板、HTML 示例
  scripts/filmkit.py         素材探测、抽帧、HTML 工作台与基础导出
  scripts/selftest.py        离线合成素材自检
  使用指南.html              下载后可本地打开的图文指南
  validation.json           已检查范围及未测试项目
  MANIFEST.sha256           包内文件校验清单
```

本地脚本使用 Python 3.10+；探测、抽帧和视频导出还需要 FFmpeg 与 ffprobe。没有这些工具也可以先完成文字设计。[脚本用法](love-memoir-film/references/local-tools.md)

## 版本与验证

v1.0.0 已在 Windows、Python 3.12.10、FFmpeg 9.0 环境通过 8 项离线合成素材测试，覆盖实际 MP4 导出、中文及特殊路径、时间范围校验、短音乐拒绝、静音参数、抽帧、HTML 转义与防覆盖等。详见[验证记录](love-memoir-film/validation.json)。

这些是工具与包结构检查，不是所有模型效果保证。其他操作系统、其他助手、新用户真实素材与新生成模型结果尚未逐一验收。
